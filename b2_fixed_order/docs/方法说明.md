# 方法说明

## 1. 为什么修复分类头

类别10在学习自身后能够达到较高准确率，学习类别11后却接近0，并主要流向类别11。冻结特征上的线性分类仍能分开两类，说明表征没有完全消失，极端失败主要来自最终线性边界失衡。因此B2保持特征提取网络冻结，只重建解析分类头。

## 2. Centered Ridge

给定特征矩阵X和one-hot标签Y，先中心化X与Y，再解带L2正则的线性系统，最后恢复偏置。项目固定L2=1.0、float64和CPU解析求解，避免把validation或official test用于超参数搜索。

## 3. 递归充分统计量

Ridge求解只需要样本数、特征和、标签和、X转置乘X以及X转置乘Y。这些统计量在类别阶段之间可加，因此新类别到来时可以合并统计量并重算同一解析解，不必长期保存全部旧样本特征。

项目在三个随机种子、15个外层折上验证递归解与批量解的预测、混淆矩阵和指标精确一致，最大logit误差不超过5.98e-12；统计量存储约为旧逐样本特征存储的74.71%。

## 4. B2边界

B2是纯解析Ridge主方案。实验曾检验额外校准增强，但其总体准确率下降0.1538个百分点，超过预注册的0.1个百分点预算，因此没有进入公开方法。
