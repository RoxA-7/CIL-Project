# 复现说明

## 环境

- Python 3.10或3.11
- PyTorch 2.1或更高
- pytest 8.3.5（验证）

## 外部输入

本仓库不包含数据、图片、模型检查点或特征工件。使用者需要自行准备合法数据与冻结模型，严格区分train、validation和official test，并为输入生成SHA256。

统计量构建入口接受公开输入协议`b2_feature_input_v1`。建议目录来自`configs/examples/b2_portable_example.yaml`，不要在提交文件中写本机绝对路径。

## 推荐顺序

1. 安装依赖并运行核心测试；
2. 从train-only特征构建充分统计量并运行独立审计；
3. 对单随机种子执行B2类别12评价并审计；
4. 冻结方案后聚合三个随机种子；
5. validation和official test只能用于最终确认，不能用于搜索L2、阈值或其他规则。

关键入口位于`tools/`。每一步都应保存请求、输入SHA、结果、审计报告与完整文件SHA。
