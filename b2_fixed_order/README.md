# 固定顺序解析递归 Ridge B2

本仓库候选版公开本项目当前固定类别顺序下的解析递归 Ridge B2 方法。它解决的核心问题是：模型学习类别11后，已经学会的类别10几乎全部被判为类别11；在继续学习类别12时，还要保持类别10、类别11和类别0—9。

B2冻结特征提取网络，以可加的充分统计量递归更新 centered Ridge 分类头。公开版只保留B2核心、直接数学依赖、最小运行/审计入口和核心测试，不包含数据、权重、逐样本预测、历史实验实现或完整内部日志。

## 主要结果

固定顺序、train-only五折OOF的三随机种子均值：类别10为62.60%，类别11为68.40%，类别12为79.27%，类别0—9宏平均为96.48%，总体为90.39%，三类调和均值为69.42%。类别11相对原生头下降，因此结论是“稳定平衡改善并伴随真实权衡”，不是无代价解决。
