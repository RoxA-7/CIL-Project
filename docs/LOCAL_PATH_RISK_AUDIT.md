# 本机路径风险审计

审计范围：本地整合分支中的已跟踪文本文件。

## 结论

- 未发现私钥、GitHub令牌或大于10 MiB的跟踪文件。
- 普通README中的固定Python路径已改为`python`命令。
- 备份清单中的本机备份根目录已替换为`<LOCAL_BACKUP>`。
- 仍有126处本机绝对路径，全部位于历史结果证据：110处在`cil_restart/results/tidy/`，15处在`cil_restart/results/raw/`，1处在`cil_restart/results/summary/`。

## 为什么没有直接替换

raw日志是原始事实源，tidy和summary由raw生成。直接手工替换会改变历史工件内容、破坏既有哈希和证据链。本分支只记录风险，不改写这些实验数据。

## 后续公开建议

仓库保持Private时可以保留原始证据。若未来转为Public，应与所有协作者先冻结原始工件哈希，再由确定性脱敏脚本生成公开副本；公开副本中的路径字段改为相对路径或语义占位符，原始工件保存在非公开归档。
